# linear-regression
This project builds a linear regression model to predict mobile phone package prices based on features:
•  Data (GB): Total internet allowance included in the package.
•  Talk Time (Minutes): Local or national call minutes provided.
•  SMS Count: Number of text messages included.
•  Validity (Days): Duration of the active package.
•  Price: Target variable representing the package cost.
# Project Overview Goal: 
⦿ Predict mobile package prices.
⦿ Method: Simple and multiple linear regression.
⦿ Language: Python.
